Web Application

Introduction: A cricketing platform displaying events and matches taking place across the cricketing world. MVP consists of creating an informational website that displays data for users regarding matches, player statistics and more. Further phases will add user authentication, fantasy league and data analysis along with deployment. Inspiration is CricInfo.

Tech Stack:

Front-end: Reactjs, tailwind CSS, Nextjs
Database: PostgresQL, Prisma ORM
Back-end: Nodejs, Expressjs

Progress: Working on Prisma Schema
